# Stimulus features

Features are shared across participants and stored once per story.
Current files: 100-Hz envelope, 50-Hz Mel, 50-Hz wav2vec2 layer 9, 50-Hz BERT, and 12-layer word-level BERT.
feature_manifest.tsv uses paths relative to the dataset root. Its scientific values and legacy provenance are unchanged.
word2vec_100hz is a documented unfilled feature family in this version.
Different temporal versions must not be silently substituted.
