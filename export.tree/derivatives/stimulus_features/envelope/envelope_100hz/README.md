# Frozen speech-envelope inputs

This directory contains 50 one-dimensional 100-Hz speech-envelope arrays.
Files are named `<story_id>_envelope.npy` and contain finite float64 values.

These are frozen legacy stimulus features. The package does not include the
original end-to-end extraction workflow needed to reproduce these exact arrays
from the released audio. The metadata/documentation correction did not change
or regenerate any array.

Technical-validation analyses/results are deferred to a future dataset update.
The presence of these envelope inputs does not establish that those
analyses or their results are reproducible from this package.
